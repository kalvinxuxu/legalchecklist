# 本地合同审查验证

部署到 Vercel/Railway 前，先在项目根目录运行：

```powershell
$env:PYTHONPATH = "backend"
python backend/scripts/local_contract_smoke.py "示范文件\20220916联合体协议书final.pdf"
python backend/scripts/local_contract_smoke.py "C:\path\to\contract.docx"
```

本地 smoke 模式不调用 LLM，验证以下链路：

- PDF/DOCX 文本是否可提取
- PDF 是否生成 UnifiedDocument、page/block/span、稳定 ID 和 bbox
- PDF 是否能生成结构化 chunk
- 证据 quote 是否能回溯到 span/page/bbox
- 扫描 PDF 是否被识别为需要 OCR
- 真实审查时，合同条款是否进入 contract chunk BM25/pgvector → RRF → Rerank 链路

要验证真实 AI 审查，需要先启动本地 PostgreSQL 和 API/worker，配置 `DATABASE_URL`、`JWT_SECRET`、LLM/Embedding key，再使用 `--live` 进行接口联调。没有中文 OCR 语言包的扫描 PDF 会明确失败，不应带着失败结果部署。

生产 PostgreSQL 先执行 `backend/migrations/001_hybrid_fts.sql` 和 `backend/migrations/002_pgvector_contract_chunks.sql`。设置 `VECTOR_STORE=pgvector`；未配置 Embedding key 时仍可用 BM25，但结果会标记为 `contract_bm25_rerank`。
